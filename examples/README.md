# Example Datasets

This directory contains representative sample business datasets used for testing, demonstration, and validation of Aivara Insight Lite.

## Included Files
- `Inventory-Records-Sample-Data.xlsx` & `inventory_sample.csv`:
  - **Archetype**: Snapshot / Inventory
  - **Domain**: Commerce & Inventory
  - **Columns**: Product ID, Product Name, Opening Stock, Purchase/ Stock in, Number of Units Sold, Hand-In- Stock, Cost Price Per Unit (USD), Cost Price Total (USD)
- `Project-Management-Sample-Data.xlsx` & `project_sample.csv`:
  - **Archetype**: Project & Task Timeline
  - **Domain**: Project Management
  - **Columns**: Project Name, Task Name, Assigned to, Start Date, Days Required, End Date, Progress
