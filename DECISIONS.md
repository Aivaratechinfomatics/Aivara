## Detailed Records

### D1: Deployment Model
- **Context:** Aivara Insight Lite is deployed for teams to inspect business data.
- **Decision:** Small shared team, single instance with per-session isolation in `st.session_state` and atomic SQLite state storage for budgets and caching.

### D2: Authentication Strategy
- **Context:** The app must be secure against unauthorized network access.
- **Decision:** Primary auth via reverse-proxy headers (`X-Forwarded-User`, `Remote-User`). Standalone mode supports a shared secret / token gate. Fails closed if auth is mandated but unconfigured.

### D3: Forecast Tab Handling
- **Context:** The Forecast tab currently exists as a placeholder or incomplete feature.
- **Decision:** Hide the incomplete stub from the v1.0 UI tab registry. Move advanced time-series forecasting to the product backlog.

### D4: PPTX Chart Engine
- **Context:** Slide decks include charts generated by Plotly. Kaleido is used to convert Plotly figures to PNG.
- **Decision:** Retain Kaleido with subprocess execution timeouts to prevent container hangs. If Kaleido fails or times out, degrade gracefully with a placeholder on the slide.

### D5: LLM Data Egress & Label Redaction
- **Context:** Data sent to OpenRouter should not inadvertently leak customer or employee names.
- **Decision:** Enable categorical pseudonymization / label redaction by default (`AIVARA_LLM_REDACT_LABELS=true`), replacing entity names with tokens before dispatch and mapping back locally.

### D6: Tier-2 Column Classification
- **Context:** Tier-2 LLM-based column classification is defined but unwired.
- **Decision:** Remove the unwired Tier-2 LLM classification prompt. Heuristic classification in `classifier.py` already handles all standard business columns deterministically without token egress.

### D7: Software License
- **Context:** The repository currently has no LICENSE file.
- **Decision:** Propose Apache 2.0 or MIT. Awaiting explicit confirmation from project owner.

### D8: Hosting Target & CI/CD Deployment
- **Context:** Deployment instructions and container configuration are required.
- **Decision:** Support Docker and `docker-compose`. CI executes container smoke tests without automatic production deploy triggers.

### D9: Supported Data Scale Limits
- **Context:** Ingestion of unbounded files risks out-of-memory crashes on containerized hosts.
- **Decision:** Impose hard limits of 100 MB and 500,000 rows. Files exceeding these limits are cleanly rejected with a helpful user notice.

### D10: LLM Provider Architecture
- **Context:** Need predictable API behavior while preserving future extensibility.
- **Decision:** Standardize on OpenRouter as the primary gateway, structured behind a clean provider interface.
